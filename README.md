# 🎬 Prime Video Clone

A Prime Video inspired website UI built using HTML and CSS.

## 📌 About The Project

This project is a front-end clone inspired by the Amazon Prime Video website. It features a dark theme, navigation bar, hero banner, movie sections and interactive movie cards.

## 🚀 Features

- Responsive navigation bar
- Prime Video style homepage
- Hero banner with Mirzapur
- Movie and TV show sections
- Movie card hover effects
- Movie details on hover
- Language dropdown menu
- Genres dropdown menu
- User account dropdown menu
- Top 10 ranking movie cards
- Interactive buttons and icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
